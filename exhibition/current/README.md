# Current exhibition

This directory contains every presently valid and up-to-date CBSC-ZDC visual.

- Epoch-dependent loss and diagnostic plots extend through the latest observed
  epoch, including labeled negative/quarantined evidence.
- Accepted-best plots identify the checkpoint selected only by validation loss;
  they are not forced to the numerically latest epoch.
- Static architecture, data-contract, and scientific-boundary graphics remain
  current only while their underlying contract remains unchanged.
- No current visual may be sourced from a historical test study for model
  selection.

Open `index.html` for the complete current gallery. The machine-readable layout
and outside-exhibition exception contract is `../visual_layout.json`.
