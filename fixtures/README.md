# Synthetic ROOT schema fixture

`outfile_neutron1_schema_fixture.root` is generated by
`scripts/build_root_schema_fixture.py`. It contains 1,000 synthetic primary
neutrons and empty ECAL/HCAL hit collections. It contains no production events
and must not be used for training, validation, metrics, or physics claims.

Its only purposes are to pin the configured EDM4hep branch spellings/types and
to test primary-neutron selection. The file is the sole tracked exception to
the repository-wide `*.root` ignore rule. The generator fixes the ROOT UUID and
metadata timestamps so rebuilding at the documented output basename is
byte-reproducible (ROOT embeds that basename in the file header).
